
# Personal Mini-Toolkit

## Project Description
The Personal Mini-Toolkit is a Python program that combines three useful tools in one application.

## Tools Included

1. Simple Calculator – Performs addition, subtraction, multiplication and division.
2. To-Do List – Allows users to add, view and remove tasks.
3. Number Guessing Game – Challenges users to guess a randomly generated number between 1 and 10.

## Python Concepts Used
- Variables
- Input and output
- Conditional statements
- Loops
- Lists
- Functions
- F-strings
- Random numbers
- Error handling

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```bash
python3 toolkit.py
```

5. Select a tool from the menu.
