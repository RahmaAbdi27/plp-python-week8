
PERSONAL MINI-TOOLKIT PROJECT PLAN

1. TOOLS SELECTED

Tool 1: Simple Calculator
The calculator performs addition, subtraction, multiplication and division.

Tool 2: To-Do List
The to-do list allows users to add, view and remove tasks.

Tool 3: Number Guessing Game
The game challenges users to guess a randomly generated number between 1 and 10.

2. MENU TEXT

Welcome to My Personal Mini-Toolkit!

Please select a tool:

1. Simple Calculator
2. To-Do List
3. Number Guessing Game
4. Quit

Enter your choice:

3. PYTHON CONCEPTS USED

Simple Calculator:
- Variables
- User input
- Conditionals (if/elif/else)
- F-strings

To-Do List:
- Lists
- While loops
- Conditionals
- Append and remove methods

Number Guessing Game:
- Random numbers
- While loops
- Conditionals
- User input
- F-strings

4. PROGRAM STRUCTURE

The program will display a menu repeatedly until the user chooses Quit.
Each menu choice will run its corresponding tool.
Invalid choices will display a polite error message.
The program will end with a friendly goodbye message.
